# 🎓 ADS — Análise e Desenvolvimento de Sistemas

📚 Repositório de estudos do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

Aqui ficam organizados os conteúdos, exercícios e trabalhos das disciplinas, separados em diretórios independentes para que cada assunto possa ser estudado separadamente.

## 🎯 Objetivos

- 📖 organizar o material de estudo das disciplinas do curso;
- 💻 guardar exemplos práticos de implementação;
- 🧩 resolver e registrar os exercícios de cada conteúdo;
- 🏗️ entregar os trabalhos práticos de forma versionada;
- 🚀 construir uma base sólida em programação e desenvolvimento de sistemas.

## 🚀 Como utilizar

Clonar o repositório:

```bash
git clone https://github.com/ademirtech10/ADS_Analise_e_Desenvolvimento_de_Sistemas.git
cd ADS_Analise_e_Desenvolvimento_de_Sistemas
```

Entrar na disciplina e no conteúdo desejado:

```bash
cd Estrutura_de_Dados/Pilha
```

Os exemplos estão em **Python 3** e podem ser executados com:

```bash
python nome_do_arquivo.py
```

## 📌 Padrão de organização

```
Conteudo/
├── README.md     → teoria e exemplos
├── Exercicios/   → exercícios resolvidos
└── Trabalho/     → trabalho prático da disciplina
```
